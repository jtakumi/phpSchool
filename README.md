# phpSchool
programing school php lesson  
入力された文字のタイプを調べるプログラム  
奇数か偶数か

## PHP の要件
- PHP 8.3 以上(`composer.json` の `require` を参照)
- 2026-10-21 公開のセキュリティリリースで修正された脆弱性(CVE-2026-109618 / CVE-2026-109619、リモートコード実行)の修正版を使用してください
  - 公式版: 8.5.12 / 8.4.27 / 8.3.36 以上(8.2 系は 8.2.35 以上)
  - Ubuntu などのディストリビューション版は、バージョン番号が変わらないままバックポートされることがあるため、ベンダーのパッチ済みパッケージに更新してください
